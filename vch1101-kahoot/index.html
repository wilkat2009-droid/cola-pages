① 開一個免費帳號

去 kahoot.com → Sign up → 揀 Teacher。免費方案（Kahoot! Go）嘅玩家上限要看你註冊時揀嘅身份：

• K-12 教師（中小學老師）＝ 一場 40 人（一般班級夠用）
• 大專／大學教師、個人、學生帳號 ＝ 一場 10 人
• 付費 Plus 50 人起、EDU 校園版 800–2000 人

唔確定自己係邊種？開場嗰陣 lobby 會直接寫「最多 X 位玩家」；或者去帳號設定睇方案。若你嘅上限係 10 人，用分隊玩法（見 ④）或改用自家版（無上限）。

② 匯入題目檔

Create → Add a Kahoot → Add question → Import → Import spreadsheet → 將 .xlsx 拖入去 → Upload。21 題一次過入晒。

③ 開場

撳 Go live → Classic。大屏（學生電腦鏡像嗰塊）會顯示 PIN。學生用手機瀏覽器入 kahoot.it，輸入 PIN 同花名，唔使裝 app、唔使 login。

④ 建議開小隊模式

Go live → 揀 Team／小隊 mode：2–4 人圍一部機，一隊算一個玩家，順便解決「有人縮咗喺度」。口號一致先按得—SEN 班最啱，冇人淘汰、冇人靜雞雞走。注意：小隊模式喺部分方案（例如免費大專版）只准 5 隊，總人數亦唔可以超過你方案嘅玩家上限。

⑤ 計分點處理

Kahoot 自己計分，你唔再收手機分。答完即場講 💡 呢一題嘅理由（見下面答案表），先至係温書，唔係純粹競賽。
