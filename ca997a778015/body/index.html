什麼情況要盡快找醫護人員

①只有一邊小腿突然又腫又硬、痛、摸上去發熱、發紅 → 當日內聯絡家庭醫生或去普通科門診。不要按摩、不要熱敷。
②如果同時呼吸困難、胸痛、咳血 → 立即致電 999 或去急症室。
③膝蓋突然卡住、伸不直、鎖住，或突然完全站不住 → 盡快就醫。
④靜脈曲張的位置破皮、流血不停；或腿上有傷口、潰瘍超過兩星期還未好；皮膚又痛又熱又腫 → 盡快就醫。
⑤小腿或腳突然冰冷、發紫、麻痺 → 急症。
⑥腳或腿又熱、又痛、又紅，或者腳部滲液、潰爛 → 盡快就醫。
⑦腳氣蔓延到手或其他部位；或按指示用藥幾星期都沒有改善 → 覆診。
⑧分不清是濕疹還是真菌 → 由醫生分辨，不要自己試藥。
這些情況大多數最後都不是大問題，但早一點找人看會穩陣些。身體有哪裡不對勁又拿不準，直接問家庭醫生就好。
求助路徑：家庭醫生 → 醫管局普通科門診 → 緊急 999。
